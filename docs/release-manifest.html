DenOS 0.5.7 source manifest

This is the DenOS 0.5.7 terminal-edition source archive. It contains no prebuilt boot ISO or host regression-test binaries. It includes the persistent denos-data.img data disk and the vendored BearSSL source checkout. The GRUB configuration uses console output and the Multiboot2 header does not request a framebuffer; the kernel enters the VGA text shell after subsystem startup. There is no GUI or window manager. Native terminal apps include a keyboard file browser, calculator, notes/editor shortcut, live system monitor, and colored-ASCII Snake, Breakout, and Maze Runner games. Aiden C samples are installed into category-matched home folders by a build-generated seed module.

Networking includes an E1000 client stack with ARP/IPv4/ICMP/UDP, DHCP, DNS A/CNAME resolution with TTL caching, a bounded synchronous TCP client, and an HTTP text reader. The normal build uses the vendored BearSSL 0.6 source, generates trust anchors from the host CA bundle, and enables TLS 1.2 HTTPS text browsing. The TLS adapter test uses an API stub and is not proof of a live server handshake.

This release includes fixes for TCP ACK processing when data is out of order, detailed BearSSL I/O failure reporting, CNAME chains, DHCP option/server validation, HTTP body truncation checks, RTC validation, and Aiden C lexer/parser and bootstrap-stack safety. make -f tests/Makefile check includes host regression suites, freestanding C checks, BearSSL compatibility probes, userland library tests, boot-source checks, and a kernel C stack-frame budget. A full ASan/UBSan suite and full-project Clang static-analysis pass are not part of this validation.

The source includes the freestanding x86-64 kernel and boot sources, PMM/heap/page-table manager and virtual allocator, DenFS v4/VFS, scheduler, IPC, services, ATA/E1000 drivers, Aiden C 5.3.0/AEX6 compiler and VM, editor completion, shell utilities, terminal apps, retained graphics/framebuffer/mouse/QOI libraries and tests, the 22-module hosted support-library prototype, ten deterministic QOI graphics fixtures, sample Aiden C programs, and subsystem documentation.

The graphics library remains in source/tests but is not initialized at boot. Terminal apps and Aiden C programs execute in kernel context: there is no ring-3 process isolation, syscall ABI, or POSIX compatibility. Aiden C is a bounded C subset, not a full ISO C implementation.

Build on a Linux host with GCC, NASM, GRUB utilities, Xorriso, mtools, GNU Make, and QEMU. HTTPS needs a system CA bundle for the normal make build; curl or wget, sha256sum, and tar are needed only when fetching BearSSL for a checkout that lacks the vendored source. make -f tests/Makefile check runs host tests and static/freestanding checks; it does not replace assembling, linking, ISO creation, or a QEMU boot test. See docs/BUILDING.md and docs/NETWORKING.md.
