DenOS 0.4.9 source manifest

This is the DenOS 0.4.9 CLI source archive. It contains no prebuilt ISO, host test binaries, persistent QEMU data disk, or GUI startup environment. It includes the freestanding x86-64 kernel and boot sources, early exception IDT/TSS fault diagnostics, separate IST1 double-fault and IST2 PIT interrupt stacks, and complete PIT IRQ register/FPU-state preservation; active-CR3 four-level page-table management with huge-page query/splitting, checked mapping APIs, NX/W^X policy and empty dynamic table reclamation; a 64 MiB PMM-backed kernel virtual allocator with rollback/quarantine and PMM ownership validation; DenFS/VFS, scheduler, IPC, services, memory management, ATA/E1000/ARP/IPv4/ICMP, Aiden C/AEX6 compiler and VM, Vim-style editor completion, shell utilities, the retained kernel graphics/framebuffer/mouse API, QOI decoder, UI font and license, 31 host test executables' source/test targets, ten 1600x900 QOI scenes with exact RGBA golden surfaces, the fixture generator, sample Aiden C applications, dedicated page-table and virtual-allocation tests, and subsystem manuals.

The large .rgba files are deterministic golden surfaces consumed by make qoi-fixtures-test. They are useful test data and account for most of the required expanded tree size; they are not loaded during OS boot.

The source can be built on a Linux host with GCC, NASM, GRUB utilities, Xorriso, and QEMU. The page-table manager currently edits one active CR3; it does not provide per-process address spaces, demand paging, TLB shootdowns, or SMP locks. Host-side tests and C compilation do not replace a QEMU boot smoke test.
