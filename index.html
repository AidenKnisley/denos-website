the surface.

DenOS is an experimental 64-bit x86 operating system built from the boot path up. Version 0.5.7 boots to a keyboard-driven text shell and adds a bounded Internet client stack with a scrollable HTTP/HTTPS web reader.

01 THE SYSTEM

More than a boot screen.
A growing set of foundations.

The 0.5.7 source tree includes a terminal-first kernel, persistent storage, a bounded network client stack, a keyboard-operated web reader, and a growing C-subset toolchain.

PHYSICAL FRAMES

Checked page tables.

A four-level x86-64 page-table manager for the active CR3, with 4 KiB mapping operations, huge-page inspection/splitting, permission checks, and a PMM-backed kernel virtual allocator.

03 / STORAGE & VFS▤

Persistent files, bounded scope.

DenFS v4 over legacy ATA PIO, nested paths up to 255 characters, migration from v1/v2/v3, copy/move operations, and VFS routing for root, proc-style views, and device-style nodes.

02 THE TOOLCHAIN

A language
inside the project.

Aiden C is DenOS's freestanding C-subset compiler. It translates a bounded language into AEX6 bytecode, which the in-kernel VM interprets. It is a genuine part of the project — and it has clearly stated limits.

// Aiden C · bounded C subset
int is_prime(int n) {
  if (n < 2) return 0;
  for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) return 0;
  }
  return 1;
}

int main() {
  printf("prime: %d\n", is_prime(97));
  return 0;
}

03 ENGINEERING STATUS

Clear about what works.
Clear about what doesn't.

DenOS is experimental. The current milestone is substantial, but the boundaries matter. This status is based on the current 0.5.7 source documentation and support matrix.

✓IMPLEMENTED FOUNDATIONS

In the current source

  • Multiboot2 boot path and x86-64 kernel
  • Memory allocator and active-CR3 page tables
  • DenFS v4, ATA PIO and VFS routing
  • Cooperative tasks, IPC, events and services
  • E1000 / ARP / IPv4 / ICMP / UDP / DHCP / DNS / TCP
  • HTTPS via BearSSL TLS 1.2 and a keyboard-driven web reader
  • Aiden C 5.3.0 / AEX6, PNG/QOI/BMP viewing
View support matrix ↗
!IMPORTANT LIMITS

Not production boundaries

  • One active CR3; no per-process address spaces
  • No ring-3 isolation or stable syscall ABI
  • DenFS is not journaled; there is no AHCI/NVMe storage
  • One synchronous TCP client; no IPv6, Wi-Fi or TCP server
  • TLS 1.2 only; no TLS 1.3 or certificate revocation checks
  • Web reader is not a full browser or general JavaScript engine
  • No graphical desktop, ring-3 isolation or syscall ABI
  • Aiden C is not full ISO C or native code
Read the limitations ↗
→ROADMAP DIRECTION

What comes next

  • Filesystem checking and crash-safe metadata
  • Protected user mode and process address spaces
  • Syscall ABI and isolated execution
  • Modern storage, USB and broader hardware
  • IPv6, richer TCP and concurrent socket support
  • TLS 1.3 and certificate revocation checks
  • SDK and package tooling after ABI stability
Explore the roadmap ↗
READ THIS BEFORE INSTALLING

DenOS 0.5.7 is an experimental hobby OS, not a daily-driver replacement. Keep independent backups, use QEMU for experiments, and do not treat the current network or memory facilities as security boundaries.
